### 常见问题 / FAQ
- **Q: 为什么无法识别语音？ / Why is voice not being recognized?**
  - A: 请在“设置 -> 隐私 -> 麦克风”中确认已授予本应用权限。
  - A: Please ensure you have granted microphone access in "Settings -> Privacy -> Microphone".
- **Q: 订阅无法恢复？ / Subscription not restored?**
  - A: 请确保登录当初购买时的 Apple ID，并点击“恢复购买”按钮。
  - A: Please ensure you are signed in with the same Apple ID used for purchase and click the "Restore Purchase" button.
